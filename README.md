# 🌱 Namma-Hasiru — Plantation Tracker App

A smart Android app for green volunteers to geo-tag plants,
track 90-day survival status, and build community reforestation data.

## Tech Stack
- Kotlin
- Room Database
- Google Maps SDK
- WorkManager
- MVVM Architecture

## Features
- GPS geo-tagging of every plant
- Community tree map with color-coded markers
- 90-day survival reminder notification
- Species guide for Karnataka
- Offline-first with Room Database

## Problem It Solves
Seed balls and plantation drives have no follow-up.
Namma-Hasiru tracks whether trees actually survived.
